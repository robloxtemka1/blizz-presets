# Пресеты фильтров — Mini App для Telegram-бота

Статическая страница (HTML/CSS/JS, без сервера) для правки пресетов фильтров кошельков.

- Пресеты приходят в адресе после `#` — эта часть адреса не уходит на сервер страницы.
- Изменения отправляются боту через `Telegram.WebApp.sendData`. Бот принимает их только от владельца, проверяет по
  схеме и сохраняет.
- Страница ничего не хранит и никуда, кроме бота, данных не отправляет.
- Через страницу меняются только пресеты фильтров. Ордеров и платных задач здесь нет.

Файлы: `index.html`, `style.css`, `app.js`, `fields.js` (список полей с описаниями и примерами — генерируется ботом).
